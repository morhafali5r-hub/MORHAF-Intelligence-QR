دليل استخدام MORHAF Studio

كل ما تحتاج معرفته لإنشاء وتخصيص ونشر صفحاتك و QR Codes بشكل احترافي — من الصفر إلى الاحتراف

🚀البدء السريع مجاني

  1. افتح تبويب ◆ Studio من الأعلى لتوليد QR Code
  2. اختر نوع البيانات من قائمة Data Protocol
  3. املأ الحقول المطلوبة (رابط، نص، واي فاي، جهة اتصال...)
  4. اضغط ◈ Preview لمعاينة مباشرة على اليمين
  5. صدّر بـ ⬇ Export PNG أو ◆ Export SVG
💡 نصيحة: يبدأ QR بالتحديث تلقائياً بمجرد الكتابة — لا حاجة للضغط على Preview كل مرة.

📋أنواع البيانات المدعومة

  • Universal: روابط أو نصوص حرة
  • WiFi: يتصل بالشبكة تلقائياً عند المسح
  • vCard: بطاقة اتصال رقمية (اسم، هاتف، إيميل)
  • Secure Email: يفتح الإيميل مع موضوع جاهز
  • Cloud Image ◆ · Morse ◆ · No Code Web ◆ · HTML ◆

💾حفظ الملفات على الجوال

عند الضغط على Export، ستظهر لك نافذة مشاركة النظام حيث يمكنك:

  • حفظ الملف في الصور أو التنزيلات
  • إرساله مباشرة عبر واتساب / تيليجرام / إيميل
  • رفعه لـ Google Drive أو أي تطبيق آخر
💡 على الكمبيوتر يتم التنزيل مباشرة إلى مجلد التنزيلات.

🛡️المصفوفة الخفية (Stealth Matrix) PRO

تقنية LSB Steganography لإخفاء رسالة سرية + ملف داخل QR:

  1. افتح قسم Stealth Matrix
  2. اختر Enabled
  3. أدخل كلمة مرور قوية
  4. اكتب الرسالة السرية
  5. ارفع ملفاً سرياً (اختياري)
  6. صدّر PNG — سيحتوي على الرسالة مخفية
⚠️ مهم جداً: اصدّر كـ PNG فقط — ميزة Stealth لا تعمل مع SVG.

🖼️Cloud Image Vault PRO

  • الرابط يوضع داخل QR
  • عند المسح، يُفتح الرابط وتظهر الصورة
💡 يدعم الرفع المتقطع (Chunked) — يمكنك رفع ملفات كبيرة بأمان.

📻Morse Audio PRO

  • سيتم توليد QR يحتوي على شفرة مورس
  • عند المسح، يمكن تشغيلها صوتياً أو تحميلها WAV

📋Lead Capture Forms + Inbox PRO جديد!

أقوى ميزة لأصحاب الأعمال — اجمع بيانات العملاء مباشرة عبر QR!

مثالية لـ: عيادات · مطاعم · معارض عقارات · صالات رياضية · متاجر

🎯كيف تشتغل؟

  1. أضف بلوك 📋 Form في منشئ المواقع
  2. خصص الحقول (اسم، جوال، إيميل، رسالة، ملف...)
  3. انشر الموقع واحصل على QR
  4. العميل يمسح QR → يعبي النموذج → يرسل
  5. البيانات تُخزّن في Google Drive تلقائياً
  6. افتح تبويب 📬 Inbox لمشاهدة كل الـ Leads

🔧تخصيص النموذج

  • عنوان النموذج: ما يظهر في الأعلى
  • الحقول: أضف/احذف/رتب بالسحب
  • أنواع الحقول: نص، جوال، إيميل، منطقة نص، قائمة، ملف، تاريخ
  • مطلوب: فعّل/عطّل لكل حقل
  • زر الإرسال: غيّر النص
  • رسالة النجاح: ما يظهر بعد الإرسال

📬Leads Inbox

شاشة جديدة كاملة لعرض وإدارة كل الطلبات:

  • 🔍 بحث في الأسماء والبيانات
  • 📥 تصدير كل البيانات CSV
  • 🔄 إعادة تحميل فوري
  • 📞 اتصل مباشرة
  • 💬 رد على واتساب
  • 📧 أرسل إيميل
  • ⭐ تمييز كمهم
  • ✓ تمييز كمقروء
  • 🗑️ حذف

💾كيف تُخزّن البيانات؟

كل submission يُحفظ كملف JSON على Google Drive في:

  • MORHAF Studio/Forms/[formId]/
  • اسم الملف: [siteId]-[timestamp].json
  • البيانات كاملة: اسم، جوال، إيميل، كل الحقول
  • يعمل من أي جهاز — كله على السحابة
💡 البيانات محفوظة في Google Drive تبعك — أنت المتحكم الوحيد!

💻محرر HTML احترافي PRO

محرر VSCode كامل داخل المتصفح لكتابة صفحاتك بحرية:

  1. من Data Protocol اختر PUBLISH HTML CODE
  2. اكتب كود HTML / CSS / JavaScript
  3. شاهد المعاينة المباشرة على اليمين
  4. اضغط ◆ APPLY & PUBLISH لنشر موقعك

✨ميزات المحرر

  • إكمال تلقائي للأكواد (Auto-complete)
  • تلوين الصيغة (Syntax Highlighting)
  • إغلاق الأقواس والعلامات تلقائياً
  • معاينة حية مع تأخير ذكي (Debounced)
  • يمكنك كتابة أي كود HTML / CSS / JS

🎨أفكار لاستخدام المحرر

  • صفحة هبوط لمنتجك
  • بطاقة عمل تفاعلية
  • دعوة زفاف / مناسبة
  • معرض صور شخصي
  • نموذج تواصل
  • أي فكرة تخطر ببالك!
💡 المحرر يدعم مكتبات CDN خارجية — يمكنك استيراد أي مكتبة JavaScript.

📤نشر مشروعك

  1. بعد إنهاء التصميم، اضغط ◆ APPLY & PUBLISH
  2. سيظهر لك Site ID — احفظه في مكان آمن!
  3. سيتم توليد رابط نشر للزيارة
  4. يمكنك مشاركة الرابط مباشرة أو تضمينه في QR

🔗متى يظهر خيار "تحديث أم موقع جديد"؟

عندما تنشر موقعاً لأول مرة، ستحصل على Site ID. عند التعديل في المرة القادمة:

  • ♻️ Update Existing: يحتفظ بنفس ID والرابط — فقط يتحدث المحتوى
  • ✨ Create New: يولّد ID جديد ورابط جديد و QR جديد
💡 استخدم Update إذا كنت قد طبعت QR مسبقاً — سيبقى يعمل مع نفس الرابط!

📂تحميل مشروع موجود

  1. اضغط زر 📂 LOAD في أي محرر
  2. أدخل Site ID الذي حفظته
  3. أدخل كلمة المرور إن وُجدت
  4. سيُفتح مشروعك للتحرير مباشرة
⚠️ إذا لم تحفظ الـ ID، لن يمكنك تحرير موقعك لاحقاً.

🔗دمج الموقع مع QR

بعد النشر، يعود بك النظام تلقائياً إلى استوديو QR مع:

  • رابط الموقع مُدخل في حقل النص
  • QR جاهز للمعاينة
  • يمكنك تخصيصه ثم تصديره
💡 هذا يعني أن QR الخاص بك سيفتح موقعك مباشرة عند المسح!

🔍فك تشفير QR Code

ثلاث طرق لفك تشفير أي QR:

  • ◈ Upload: ارفع صورة QR من جهازك
  • ◉ Live Scan: امسح مباشرة بالكاميرا
  • 📻 Morse (PRO): ارفع ملف WAV لفك مورس

🛡️فك تشفير الملفات السرية PRO

  1. اذهب لتبويب ◈ Decoder
  2. أدخل كلمة المرور في الحقل السري
  3. ارفع صورة QR التي تحتوي على رسالة مخفية
  4. سيفك النظام التشفير تلقائياً ويعرض الرسالة + الملف
💡 إذا لم تُدخل كلمة المرور، سيتم فك QR العادي فقط (بدون الكشف عن المحتوى السري).

📻فك شفرة مورس PRO

  1. اذهب لتبويب 📻 Morse في Decoder
  2. اختر القاموس (عربي / إنجليزي)
  3. ارفع ملف .wav
  4. سيتم تحليل الصوت واستخراج النص تلقائياً

✨ماذا يحدث بعد فك التشفير؟

  • روابط: يظهر زر "زيارة الموقع"
  • واي فاي: عرض اسم الشبكة وكلمة المرور + زر نسخ
  • بطاقة اتصال: عرض البيانات + أزرار الاتصال
  • صور: عرض الصورة مباشرة
  • نصوص عامة: زر نسخ سريع
