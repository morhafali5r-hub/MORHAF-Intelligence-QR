MORHAF Studio User Guide

Everything you need to create, customize, and publish your pages and QR codes professionally

🚀Quick Start Free

  1. Open Studio tab
  2. Choose data type from Data Protocol
  3. Fill in the fields
  4. Click Preview
  5. Export PNG or SVG
Tip: The QR updates automatically as you type.

📋Supported Data Types

  • Universal: Links or free text
  • WiFi: Auto-connects on scan
  • vCard: Digital contact card
  • Secure Email: Opens email with subject
  • Cloud Image PRO / Morse PRO / No Code Web PRO / HTML PRO

💾Saving on Mobile

When you click Export, you'll see the system share dialog:

  • Save to Photos or Downloads
  • Send via WhatsApp / Telegram / Email
  • Upload to Google Drive

🎭Pattern Library 14 Styles

Open Design & Aesthetic Matrix section:

  • Free: Classic - Dots - Minimal
  • PRO: Rounded - Classy - Diamond - Cyber - Holographic - Cosmic

🎨Custom Colors

  • Foreground: Dots color
  • Corners: Corner squares color
  • Background: Background color
  • Color Presets: 10 ready-made presets (some PRO)
Important: Ensure strong contrast between foreground and background for good scanning.

🌈Gradient Fill PRO

Choose Linear or Radial:

  • Drag the dial to change angle
  • Pick start and end colors
  • Adjust stops (Stop 1 / Stop 2)
  • Live CSS preview at the bottom

🖼Center Logo PRO

  • Upload logo from device
  • Appears in center of QR
  • Auto-extracts smart color palette
  • Apply palette to dots or as gradient
Use PNG logo with transparent background for best results.

📐Export Resolution

  • 720p: Fast digital use
  • 1080p: Default - great for web
  • 2K: Standard print
  • 4K: Large format print and billboards

🛡Stealth Matrix PRO

LSB Steganography to hide a secret message + file inside the QR:

  1. Open Stealth Matrix section
  2. Select Enabled
  3. Enter a strong password
  4. Write your secret message
  5. Upload a secret file (optional)
  6. Export PNG - it will contain hidden data
Very Important: Export as PNG only - Stealth doesn't work with SVG.

🖼Cloud Image Vault PRO

Turn any image into a shareable cloud link:

  • Upload image - stored on Google Drive
  • Direct link generated automatically
  • Link embedded inside QR
  • Scanning opens the link and shows image
Supports chunked upload - safe for large files.

📻Morse Audio PRO

Convert text to playable Morse code:

  • Choose dictionary (Arabic / English)
  • Type your message
  • QR will contain the Morse code
  • Scan to play audio or download WAV

📋Lead Capture Forms + Inbox PRO New!

Collect customer data directly via QR code!

Perfect for: Clinics - Restaurants - Real Estate - Gyms - Stores

🎯How it works

  1. Add a Form block in Site Builder
  2. Customize fields (name, phone, email, message, file...)
  3. Publish site and get your QR
  4. Customer scans QR - fills form - submits
  5. Data saved to Google Drive automatically
  6. Open Inbox tab to view all leads

🔧Form Customization

  • Title: What appears at top
  • Fields: Add/remove/reorder by drag
  • Field types: Text, phone, email, textarea, dropdown, file, date
  • Required: Toggle per field
  • Submit button: Change text
  • Success message: What shows after submit

📬Leads Inbox

Full screen for viewing and managing all leads:

  • Search by name, phone, data
  • Export CSV
  • Instant reload
  • Call directly
  • Reply on WhatsApp
  • Send email
  • Star as important
  • Mark as read
  • Delete

💾How data is stored

Each submission saved as JSON on Google Drive in:

  • MORHAF Studio/Forms/[formId]/
  • Filename: [siteId]-[timestamp].json
  • All data: name, phone, email, all fields
  • Works from any device - all in cloud
Data saved to your Google Drive - you control it entirely!

💻Professional HTML Editor PRO

Full VSCode editor inside the browser for writing pages freely:

  1. From Data Protocol select PUBLISH HTML CODE
  2. Write HTML / CSS / JavaScript
  3. Live preview on right side
  4. Click APPLY & PUBLISH to deploy

✨Editor Features

  • Auto-complete
  • Syntax highlighting
  • Auto-close brackets and tags
  • Live preview with smart debounce
  • Full HTML / CSS / JS support

🎨Ideas for the editor

  • Product landing page
  • Interactive business card
  • Wedding / event invitation
  • Personal photo gallery
  • Contact form
  • Any idea you can dream up!
Editor supports external CDN libraries - import any JavaScript library.

📤Publishing your project

  1. After finishing design, click APPLY & PUBLISH
  2. You'll see a Site ID - save it in a safe place!
  3. A publish URL will be generated
  4. Share the link directly or embed in QR

🔗Update vs New Site

When you first publish, you get a Site ID. Next time you edit:

  • Update Existing: Keeps same ID and URL - only content updates
  • Create New: Generates new ID, new URL, new QR
Use Update if you already printed your QR - it will keep working with the same URL!

📂Loading an existing project

  1. Click LOAD in any editor
  2. Enter the Site ID you saved
  3. Enter password if any
  4. Your project opens for editing directly
If you don't save the ID, you won't be able to edit your site later.

🔗Integrating site with QR

After publishing, the system returns to QR Studio with:

  • Site URL entered in text field
  • QR ready for preview
  • You can customize and export it
This means your QR will open your site directly when scanned!

🔍Decode QR Code

Three methods to decode any QR:

  • Upload: Upload QR image from device
  • Live Scan: Scan directly with camera
  • Morse (PRO): Upload WAV file to decode Morse

🛡Decode Stealth Files PRO

  1. Go to Decoder tab
  2. Enter password in secret field
  3. Upload QR image with hidden message
  4. System will decrypt and show message + file
If you don't enter password, only normal QR will be decoded (secret content won't be revealed).

📻Decode Morse PRO

  1. Go to Morse tab in Decoder
  2. Choose dictionary (Arabic / English)
  3. Upload .wav file
  4. Audio analyzed and text extracted automatically

✨What happens after decoding?

  • Links: "Visit Site" button appears
  • WiFi: Shows network name and password + copy button
  • vCard: Shows data + call buttons
  • Images: Displays image directly
  • Plain text: Quick copy button
